# BetSwitch

![BetSwitch Logo](https://user-images.githubusercontent.com/placeholder/logo.png)

BetSwitch is a web application that simplifies the betting experience by providing a user-friendly platform for converting bet codes between different bookmakers.

## 🚀 Features

- **Bet Code Conversion**: Seamlessly convert bet codes between different bookmakers
- **User Accounts**: Create an account to save your conversion history
- **Mobile Responsive**: Use BetSwitch on any device, anywhere
- **Multiple Bookmakers**: Support for major betting platforms including Bet9ja, BetKing, 1XBet, and more

## 🔍 Core Features Explained

### Bet Code Conversion

The primary feature of BetSwitch is the ability to convert bet codes between different bookmakers. Users can:

1. Enter a bet code from their source bookmaker
2. Select which bookmaker the code is from
3. Choose which bookmaker they want to convert to
4. Click convert to get the equivalent bet code for the target bookmaker

### User Authentication

BetSwitch provides a secure user authentication system:

- **Sign Up**: New users can create an account with their email and password
- **Login**: Existing users can securely access their accounts
- **Password Strength**: Real-time password strength indicator during registration
- **Social Login**: Options for quick sign-up/login via Google and Facebook (planned)

## 🚀 Getting Started

### Prerequisites

- A modern web browser
- Basic understanding of betting terms and codes

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/betswitch.git
   ```

2. Open the project folder:
   ```bash
   cd betswitch
   ```

3. Open `index.html` in your browser or set up a local server.
